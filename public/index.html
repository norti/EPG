Duplikált logó gyorsítótár kezelése

Megkeresi a gyorsítótárban (images.db) azokat az azonos tartalmú logókat, amelyeket több forrás vagy csatorna különböző URL alatt tárol, és megszünteti a felesleges redundanciát.

TMDB (The Movie Database) Integráció

Adja meg a TMDB API kulcsát vagy Read Access Tokenjét a műsorok borítóképeinek, posztereinek, értékeléseinek és leírásainak megjelenítéséhez.

TMDB gyorsítótár kiürítése
Törli az összes korábban mentett TMDB találatot az SQLite adatbázisból.

Haladó API beállítások (opcionális)

Alapértelmezésben az alkalmazás beépített Trakt Client ID-ját használja. Csak akkor add meg, ha saját Trakt API alkalmazást szeretnél használni.

Google Integráció

Google

Jelentkezzen be Google fiókjával a beállítások felhőalapú mentéséhez és a Naptár integrációhoz.

Az alkalmazás csak a saját, rejtett appDataFolder mappájához fér hozzá a Google Drive-on. Az Ön többi Drive fájljához nincs hozzáférés.

Google Drive Szinkronizáció

Beállítások, csatornaadatok mentése/visszaállítása Google Drive használatával

Újabb mentés érhető el a Google Drive-on. A visszaállításhoz kattintson a Visszaállítás gombra.
